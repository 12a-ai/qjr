# 4｜基础数据集构建

目标：基础数据既能复算，又能直接支持设计。先明确一行是什么，再定义列。

| 字段 | 类型 | 含义 | 约束 |
|---|---|---|---|
| observation_id | 字符串 | 唯一观测 ID | 非空且唯一 |
| entity_id | 字符串 | 对象身份 | 能关联对象表 |
| observed_at | 日期或时间 | 观测时点 | 保留原始精度 |
| metric_id | 字符串 | 指标身份 | 有明确定义 |
| value | 数值 | 单项观测值 | 缺失不写成零 |
| unit | 字符串 | 数值单位 | 同指标口径一致 |
| source_id | 字符串 | 出处 | 能关联来源表 |
| evidence_type | 枚举 | 转录/测量/外部/推导 | 与实际过程一致 |

上表是通用结构，选题后删去不需要字段，并补名义属性、文本或图像资源。不是提前填好的业务数据。

若一条记录有多个标签，另建 entity_id—tag_id 表；经纬度分列；图片用单个 resource_id 引用。值和单位分列，日期范围起止分列。
