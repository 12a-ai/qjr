# 2｜主题内容分析与大模型讨论

本阶段必须围绕用户给出的真实选题沟通；尚未开始具体判断。

## 讨论顺序

先问“观众看完应理解什么”；再问“主要关系是时间、从属、类别、检索还是空间”；随后决定混合图表、文字列表、时间轴等表现形式；最后决定平面、照片、手绘等风格。

| 决策 | 判断依据 | 当前结论 |
|---|---|---|
| 主导数据逻辑 | 打乱哪种关系会损害主题 | 等选题 |
| 辅助逻辑 | 局部说明需要什么关系 | 等选题 |
| 表现标签 | 阅读任务与内容结构 | 等案例 |
| 风格 | 读者、媒介、素材质量与表达目的 | 待讨论 |
| ISOTYPE | 是否有稳定图符语法或单位表达 | 待证据 |
| 词云 | 是否确需表达词频；分词与停用词是否可解释 | 不预先采用 |

照片型是表现风格，不等于地理型；文字多不等于字母表型；词云一般表达频数，不直接表达观点重要性。判断依据应从数据和任务出发。

完成条件：形成一份有取舍理由的设计定位，并由用户确认具体选题方向。不能将模型自行补出的偏好写为用户意见。
