# 5｜叙事框架搭建

每个版面段落对应一句能被证据支持的陈述。先确定字段组合及计算，再决定图形。

| 字段组合 | 能回答的问题 | 不能直接推出的结论 |
|---|---|---|
| 名称＋经度＋纬度 | 地点在哪里 | 某地点更重要 |
| 地区＋GDP值＋年份＋单位＋口径 | 某地某年经济总量是多少 | 没有分母时的人均水平 |
| 对象＋类别＋计数 | 有哪些类别、各有多少 | 类别之间的因果 |
| 事件＋日期 | 发生顺序与时间间隔 | 前一事件导致后一事件 |

这些是结构示意，未选作实际主题。

## 待填写叙事矩阵

段落 ID、读者问题、核心陈述、输入字段、公式、来源 ID、图形、解释句、限制、前后衔接。

建议流程：引入问题→给整体范围→展示比较或转折→解释例外→得出有边界的结论。检索型作品可采用“入口—索引—定位—详情”，不硬套戏剧化故事。

完成条件：任意一句结论都能回到字段与出处；任意一张图都能说清它在回答哪个问题。
