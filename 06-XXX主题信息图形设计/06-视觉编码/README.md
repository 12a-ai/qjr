# 6｜视觉编码：让关系可见

偏重设计表达，但每种视觉差异都应能解释其目的。先做数据映射，再做风格调整。

| 通道 | 可承担的含义 | 需要防止的误读 |
|---|---|---|
| 点/位置 | 对象、事件、地点或数值位置 | 随意移动地理点 |
| 线 | 关联、顺序、路径、趋势 | 装饰曲线被读成连续数据 |
| 面/面积 | 类别区、区域、规模 | 边长与面积比例混淆 |
| 体 | 需要立体结构解释的对象 | 透视遮挡被误读成数量 |
| 色相 | 无序类别 | 无序类别被误读成强弱 |
| 明度 | 有序大小或背景层级 | 同色阶同时表示多种指标 |
| 符号/图符 | 对象词汇、状态、重复单位 | 普通图标被误标 ISOTYPE |
| 图像 | 情境、实物、证据 | 裁切比例被读成真实尺寸 |
| 字距/行距/字号 | 阅读层次与分组 | 字大被误读成统计量大 |

选题后为每个真实字段填写：视觉变量、尺度、图例、冗余编码、误读检查。照片要统一处理策略，图符要统一轮廓语法，统计图要保留可读刻度。

[Gestalt 规则总览](../../04-Gestalt视觉组织原则/00-概念与规则总览.md) 可用于检查图文配对、分组、路径与主体。不能把所有原则叠加到每一张图。

完成条件：小尺寸预览仍能辨认层次，关键内容不只依赖颜色，读者能把符号与数据正确对应。
