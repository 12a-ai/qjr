# 3｜数据搜集

三类来源分别留档：[公共数据集](./01-公共数据集/README.md)、[文本文献](./02-文本文献/README.md)、[自建数据集](./03-自建数据集/README.md)。

先登记来源再采集。来源记录字段：source_id、title、publisher、url、publication_date、access_date、license、scope、limitations。日期与单位须与图面陈述匹配。

公共数据检查定义、更新频率、下载方式与许可；文献注明原始页码或段落位置，区分作者观点与原始数据；自建数据先定对象、抽样、记录方法和缺失处理，再采集。

完成条件：每条事实有来源，关键指标口径可对齐；缺失与无法核实的数据列入清单。当前尚未取得指定主题资料。
