## 每个目录放什么

每个标签目录含 `00-标签说明.md` 和 `案例/README.md`。有实际图像后才建立具体 CASE；一个作品只存一套图像与分析，其他标签链接引用。ISOTYPE 的完整转译方法继续在 [03 专题](../03-ISOTYPE信息图/README.md) 维护。

[案例接入状态](./案例接入记录.md)｜[逐图分析模板](./案例分析模板.md)｜[来源与资源模板](./来源与资源模板.md)｜[录入与回写规范](./案例录入与回写规范.md)

公共模板平铺在本目录中，不额外占用标签子文件夹。当前已收录真实新案例数量仍为 0，等待用户指定原图；新增标签说明不等于新增案例证据。
