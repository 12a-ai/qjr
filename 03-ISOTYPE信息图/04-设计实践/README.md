# 04｜设计实践

本目录记录如何把方法用于设计。当前为待实施方案，没有实际受众测试或已验证经验。

## 实践流程

1. 从真实选题中选一个可由资料回答的问题，确定读者与媒介。
2. 分析字段、计量口径与信息取舍，先写读者应理解的一句话。
3. 制定图符词汇、统计单位或非统计组合规则，再做低保真排列。
4. 加入标题、精确数值、图例与必要说明，检查其能否独立解释图意。
5. 进行理解任务或作者自查，记录误读；按证据调整图符与版式。
6. 保存数据版本、图符字典、方案变化和导出结果，再总结有条件的经验。

## 教学练习：单位选择怎样影响表达

假定两组数量分别为 17 和 29，这些数只是教学设例。一个图符代表 5 时，分别需要 3 个与 5 个完整符号，余量分别为 2 和 4。改为一个图符代表 1 时可精确计数，但需要更多空间。两种方案都要保留明确图例，比较计数负担、版面密度与近似是否容易理解。

练习不能直接推出哪种单位总是更好。若采用比较任务，尽量保持同一数据、图符和文字，只改变单位与必需的排列；记录任务条件，不把作者偏好写成受众结果。

## 实践记录模板

| 项目 | 待记录内容 |
|---|---|
| 问题与来源 | 核心命题、输入字段、出处与数据版本 |
| 方案 | 图符词汇、单位、布局、颜色、文字与余数策略 |
| 验证 | 阅读任务、参与人数、展示条件、原始回答 |
| 结果 | 正确理解、误读、耗时、反例及不确定性 |
| 修订 | 改动了什么、依据是什么、还有什么没解决 |
