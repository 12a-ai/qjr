# 01｜历史与文献

## 历史线索

ISOTYPE 的前身是 Otto Neurath 及团队在 1920 年代维也纳发展出的图像统计方法。研究其历史时，应同时关注统计内容、公共教育目的和制作分工，而非只搜集图符外观。[维也纳大学研究项目](https://isotype.univie.ac.at/en/)

约 1935 年的宣传折页介绍了 Isotype 名称及标志。维也纳大学的文献说明将名称提出与 Marie Neurath 联系起来，并将标志设计归于 Gerd Arntz。对这类档案要区分“作品约年”“术语出现”和“方法起源”，不能混写为同一个发明日期。[折页档案说明](https://isotype.univie.ac.at/en/category/documents/)

Marie Neurath 的工作包括分析材料并转为可供绘制的图像组织，常以 transformer（转译者）描述。雷丁大学馆藏还说明这种工作延伸至历史、技术和科学知识，提示我们不能将全部 ISOTYPE 实践缩减为重复小人统计。[雷丁大学馆藏](https://collections.reading.ac.uk/special-collections/collections/marie-neurath-collection/)

## 后续文献笔记格式

每条记录保存 source_id、作者或机构、标题、年份、链接、访问日期、页码或段落定位，以及“原文观点／本稿解释／待核实”状态。整理规则时回到具体段落，不把现代设计建议冒充历史原话。

历史事实与设计评价分别撰写；同一方法的不同阶段可能存在变化。新增档案支持或限制某条概念时，同步回写 [概念与方法](../00-ISOTYPE概念与方法.md)。
