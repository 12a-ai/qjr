# 02｜图符语言与视觉编码

## 从语义到视觉

先确定要解释的对象和关系，再选择图符。一个符号在同一图中应有稳定含义；如果同形符号代表不同对象，必须提供可辨识的限定。图像可以降低识别负担，但不能预设所有读者都无须文字即可理解。

[概念总论](../00-ISOTYPE概念与方法.md) 提供方法边界；[历史与文献](../01-历史与文献/README.md) 提供来源。以下是本稿的设计操作建议，不是对尚未提供的案例作观察结论。

## 视觉编码矩阵

| 通道 | 可承担的任务 | 检查问题 |
|---|---|---|
| 图符轮廓 | 区分对象或稳定词汇 | 小尺寸下能否辨认，是否需要文字 |
| 重复数量 | 表达固定单位的统计量 | 单位是否统一，能否复算 |
| 位置与基线 | 支持组间扫描和比较 | 每组起点与排列方向是否一致 |
| 色相 | 区分类别或属性 | 同色是否同义，有无冗余文字 |
| 点与线 | 定位对象、解释关系或方向 | 关系真实存在，还是仅为装饰 |
| 面与留白 | 组织类别和章节 | 是否错误包含或分割标签 |
| 体与光影 | 必要时解释结构 | 是否影响图符的可比性与计数 |
| 字距与行距 | 支持图例、标题和说明阅读 | 文字是否贴近对应对象，组间是否清楚 |

## 单位、余数与近似

统计图符明确一个完整符号代表的数量 k。对数值 v，完整符号数为 floor(v/k)，余量为 v−k×floor(v/k)。若采用部分符号，应解释比例与识别方式；无法清楚表达时保留精确数值并注明图符近似。

不要一边放大图符、一边增加重复数量，造成双重数量编码。若图符只解释类别，不承担统计量，也应在图例中说清，不能由剪影个数反推数据。

## 制作时保留的记录

图符字典一行一个 symbol_id，记录含义、资源 ID、所属类别、是否承担单位、适用范围和来源。数量映射另表记录指标、数值、单位 k、完整符号数与余量；多类别关系用关联表，不在一格填写多个 ID。

最终检查同时覆盖语义、数据比例、排列和阅读任务。统一画风只是其中一环，不能替代转译是否准确的判断。
