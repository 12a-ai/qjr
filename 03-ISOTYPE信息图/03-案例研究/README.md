## 逐图分析的六个问题

1. 面向谁解释什么，哪些原始内容被选入或省略？
2. 图符表示对象、类别、关系还是统计单位？
3. 如果图符表示数量，一个符号是多少，余数如何处理？
4. 排列、颜色、留白、文字与统计图形怎样共同组织信息？
5. 底层五类主逻辑是什么，作品的叙事顺序如何建立？
6. 哪些结论是图面可见，哪些是推断，还缺什么资料？
