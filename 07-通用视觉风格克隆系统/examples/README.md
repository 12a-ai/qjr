# 程序测试样例与四版输出

本目录全部为独立编写的软件测试数据。双色纸本风格、收音机、旅行角色与“山”字仅用于检查系统，不代表用户选题，不是从课件原图提取，也不是已生成作品。

输入：[风格档案](./fixture-profile.json)、[通用母版任务](./task-template.json)、[换主题任务](./task-switch.json)、[三帧扩展任务](./task-expand.json)、[字体迁移任务](./task-transfer.json)。保留 fixture 状态，不进入正式风格库。

完整已编译结果：

| 任务 | 输出 |
|---|---|
| 母版 | [四版母版目录](./outputs/template/) |
| 主题变更 | [四版成品与母版](./outputs/switch/) |
| 三帧扩展 | [三套四版输出](./outputs/expand/) |
| 跨品类迁移 | [字体迁移四版输出](./outputs/transfer/) |

每个任务目录有 manifest.json 和 frame 子目录；每帧恰有四个版本文件。第三版同时含通用与即用行；第四版包含中英母版与中英即用段落。纯母版任务不制造即用主题。

复跑时将 README 中的 CLI 第二输入换成对应任务，并使用一个新的输出目录，结果可与本目录进行内容比较。程序不自动访问网络、不调用图像服务，不消耗生图额度。
