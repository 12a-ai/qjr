# qjr 通用视觉风格克隆系统

输入参考图，提取不依赖题材的视觉语法；保存双语风格档案；换主体、换场景、做系列或跨品类时，从同一份档案编译四版提示词。系统不预设画风和课程选题。

本次交付包含可独立上传给视觉模型的运行指令、可执行的 Node.js 编译器、四版提示词样例与自动测试。**视觉提取由能看图的模型执行并经人工复核，本地编译器负责校验与输出，不包含图像识别模型或生图 API。**

## 直接使用

把 [单文件运行指令](./启动风格克隆系统.md) 上传到支持看图的大模型，附参考图，说“启动风格克隆系统，先提取通用母版”。之后可说“换成我的新主题”“扩展成三张系列”或“迁移为字体海报”。这个文件可以单独使用。

如果需要稳定保存、重复编译与批量输出，在仓库根目录运行（需要 Node.js 22 或更高版本，无第三方依赖）：

```powershell
node --test 07-通用视觉风格克隆系统/test/engine.test.mjs
node 07-通用视觉风格克隆系统/src/cli.mjs 07-通用视觉风格克隆系统/examples/fixture-profile.json 07-通用视觉风格克隆系统/examples/task-switch.json 交付文件/风格输出-首次运行
```

输出路径的父目录须已存在，末级目录必须尚不存在，以保护旧版本。首次命令使用的 `交付文件` 已是本地交付目录。换自己的资料时，把两个输入文件替换为自己的风格档案和主题任务。**examples 中的双色纸本样例全部是原创软件测试数据，不是指定案例、默认画风或实际提取结果。**

四版指：① 中文 JSON，② 英文 JSON，③ 中文简易提示词（母版＋即用版），④ 自然语言提示词（中英母版＋中英即用版）。自然语言的 P1/P3 固定，P2 替换主题和适配结果；短版只替换主题槽与画幅。

程序可以验证字段保持不变、数值一致与编译可重复；图像是否保持同样风格，还受生成模型与输入图质量影响。短版是五锚点摘要，无法承载长 JSON 的全部细节，复杂信息图、准确文案和多物体关系应使用完整自然语言版。此处不承诺跨所有模型获得相同像素。

保留本仓库既有 01—06 结构，所以新增专题使用 **07**；老师参考仓库中的同名专题使用 06，不能直接照搬其模块编号。本专题联动本地 [02 案例索引](../02-信息图形类型案例/案例接入记录.md)、[03 ISOTYPE](../03-ISOTYPE信息图/README.md)、[04 Gestalt](../04-Gestalt视觉组织原则/README.md)、[05 数据规范](../05-统计图形与数据规范/README.md) 和 [06 八阶段项目](../06-XXX主题信息图形设计/README.md)。
