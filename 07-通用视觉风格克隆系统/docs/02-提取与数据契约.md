# 提取方法与数据契约

## 先看图，再建立风格规则

参考图必须能实际查看。单图只支持作品层面的结论；多图先独立观察，再取稳定共性。文件名、作者名或文本描述不能代替看图。先列出原图的人物、器物、地标和文案黑名单，再将轮廓、光色、边缘、密度和张力等转换为不含具体题材的规则。

每条判断区分 `observation`（直接可见）、`inference`（媒介等推断）、`user_requirement`（用户限制）、`design_choice`（新主题设计选择）。叙事立场往往是解释而非视觉事实，应标为推断并人工复核；不能仅凭画面断言作者意图。

## 十三系统映射

| 本系统 ID | VSCF 条目 | 观察与记录对象 |
|---|---|---|
| A1 | 1 风格本体 | 媒介、边界、叙事立场、独特异常；未知流派不猜填 |
| B1 | 2 色彩 | 角色、比例、明度/饱和度、高光和阴影色偏 |
| B2 | 3 光线 | 方向、软硬、对比、功能；平涂不硬填物理色温 |
| B3 | 4 构图 | 重心、阅读路径、负空间、层次 |
| B4 | 5 尺度 | 主体与环境面积关系，避免套用统一占比 |
| C1 | 6 绘画语言 | 线宽、收笔、色块/体块塑形 |
| C2 | 7 边缘 | 焦点、次级、背景边缘的差异；不适用可说明 |
| C3 | 8 完成度 | 刻画资源集中位置与省略区域 |
| E1 | 9 信息密度 | 高低密区与阅读节奏 |
| C4 | 10 材质纹理 | 基底与笔触，不确定物理纸种不写准确克重 |
| D1 | 11 主体设计 | 风格层只存主体融入语法，具体对象移入主题槽 |
| E2 | 12 视觉锚点 | 第一落点、次级支点、停留细节 |
| E3 | 13 张力 | 以两种形态及关系动词描述，避免只写“很有张力” |

这些是本作业的观察维度，与 Gestalt 的十三个工作条目分别维护，不能混为一套学术固定总数。

## 可执行档案结构

完整形状见 [fixture-profile.json](../examples/fixture-profile.json)，这里只借用结构，不借用其测试风格。未知字段不以样例值补齐。

| 路径 | 约束 |
|---|---|
| schema_version / id / name | 版本 `1.0`、大写字母/数字/连字符 ID、中英名称 |
| status | `draft` 草稿、`reviewed` 人工复核或 `fixture` 程序测试 |
| sources | 来源 ID、位置、viewed；正式 reviewed 必须有实际文件 SHA256 |
| excluded_source_elements | 中英具体内容黑名单；自动扫描风格区内同字串泄漏 |
| style.rules | 恰好十三个 ID；每项含 state、kind、confidence、source_ids、zh、en |
| state | active、not_applicable、unknown；未解决项不能进入 reviewed |
| confidence | 0—1，属于分析者自评，不是仪器测得的概率 |
| style.parameters | 共享数值对象：palette、negative_space、subject_area、light_temperature_k |
| palette | 色彩角色＋HEX＋比例，比例合计为 1；数据色标另行遵守 05 |
| 面积区间 | 0—1 的上下界；未知为 null。主体面积/留白可能不是互补集合，不能强求相加为 1 |
| 色温区间 | 正数开尔文上下界；无法测定为 null |
| style.anchors | 五个不同且 active 的系统 ID，引用原规则，不重复维护五段翻译 |
| style.negative | 双语禁令数组，不向其中偷偷添加所有画风通用的“禁黑色”等条件 |
| style.concise_zh | 人工审定的五锚点短摘要，固定核 50—105 汉字；不宣称等价携带全部细节 |
| bridge | 双语 color、material、space，以及五类 focus 规则 |

数值只测得或估计后填写，并在相关规则中说明估计方法。HEX 若来自取色应记录区域/方法；没有测量就不把视觉印象说成精确测值。英文翻译来自同一双语值对象，数值由同一共享对象生成；程序拦截两种语言中阿拉伯数字集合不一致，但无法自动证明翻译语义完全等价。

公开四版输出不附中文短版内部摘要字段，因此英文 JSON 的描述仍使用英文。结构 ID、机器枚举、色值和数值在两版保留相同值，中文键名与英文键名一一映射。

## 新材料回写

只有图像已看过才建立正式 CASE，并存于 02 的唯一所属案例目录；在 [案例接入记录](../../02-信息图形类型案例/案例接入记录.md) 登记。风格档案只记录 `sources.location` 指向该 CASE，不重复存图。同步更新 [风格索引](../style_library/INDEX.md)、相关方法及根更新日志；如实际案例改变定义，则回写 01 或 03/04/05。当前接入的是教学材料，不为它们伪造图像 CASE。

自动黑名单检查只能拦截字串，无法可靠识别近义词、隐喻或具体物件的视觉泄漏。人工必须执行“彻底换一个主体，规则是否仍成立”的剥离检查。
