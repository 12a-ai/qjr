# ISOTYPE｜从内容到图符的转译

ISOTYPE 全称 International System of Typographic Picture Education，源自 Otto Neurath 及其团队发展的图像统计与视觉教育实践。它是一套组织、转译与传播信息的方法，不是某一种信息图形类型。Marie Neurath 的“转译者”工作说明：先分析内容，再安排可理解的图像关系，而非先选漂亮图标。[雷丁大学馆藏介绍](https://collections.reading.ac.uk/special-collections/collections/marie-neurath-collection/)

## 工作步骤

1. 明确读者要理解的比较或概念，把术语翻译成可以解释的对象。
2. 选择统一图符词汇；一个符号的含义在同一图内稳定。
3. 统计表达先规定单位 k，再计算图符数量 n=v/k。值增大时增加同尺寸图符数量，避免把同一人物随意放大。
4. 采用共同基线、排列方向与组距；图符之外保留必要的标题、数值和说明。
5. 对不能整除的数据，选择半符号、标注余量或明确近似，不靠悄悄四舍五入隐藏差异。
6. 让读者复述图意，检查其理解的是类别、数量还是象征含义。

重复单位而非放大图符的统计规则可参见 Otto Neurath 的 1936 年著作说明。[作者原著扫描](https://nordisk.pp.ru/on-line/files/%2Bblog/04C76FA2-B66A-4601-BAB0-B6F2319B2C3E/Internationa_Picture_Language._Otto_Neurath.pdf)

## 教学设例与误差

假设某类对象 23 件，一个图符代表 5 件。4 个完整图符只能精确表达 20 件；若余下 3 件没有恰当的部分图符表达，保留“23 件”精确数字并说明图符近似。不要画 5 个完整图符又不给近似说明。这里是算术设例，不是用户主题数据。

点用于定位，线用于关系，面用于分组，色相区分类别。图符大小、基线与间距宜一致，让读者比较重复次数。三维剪影和复杂纹理可能降低可比性，应按目标尺寸试读。

## 方法边界

ISOTYPE 不等于所有象形图，不等于 ISO 标准图标。单个图标可解释对象，但其存在不证明使用了 ISOTYPE。非统计教育图也可能属于其历史实践，需要来源而非外观判断。[维也纳大学研究项目](https://isotype.univie.ac.at/en/)
