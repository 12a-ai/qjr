本次新增作业：[通用视觉风格克隆系统](./07-通用视觉风格克隆系统/README.md)。可直接使用 [独立运行指令](./07-通用视觉风格克隆系统/启动风格克隆系统.md)，或运行本地编译器，输出中文 JSON、英文 JSON、中文简易提示词、双语自然语言四个版本，支持换主题、系列扩展与跨品类迁移。程序验证与视觉效果验证分别记录，未指定参考图时不虚构真实提取结果。

三个维度分开记录：**数据逻辑决定信息怎样关联；表现形式决定作品怎样呈现；设计方法决定视觉怎样组织。** 一幅图可以主属编目型，同时使用文字列表与混合图表，并运用 ISOTYPE。五类是课程工作分类，不宣称穷尽所有信息结构。

与 jzr 的实质区别：本稿用“提问—关系—字段—编码—误读检查”组织定义；将元素连接与一致连接分开讨论；增加单变量对照实验、证据等级与案例反例回写机制。所有教学设例均标明身份，不充当老师提供的案例。
